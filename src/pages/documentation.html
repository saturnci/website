Documentation

What is SaturnCI?

SaturnCI is a continuous integration (CI) tool for Ruby on Rails applications. SaturnCI supports both RSpec and Minitest.

Getting started

See the configuration guide to get SaturnCI set up on your project.

Core concepts

  • Workflows — the Ruby file that decides what runs on a commit
  • Jobs — the unit of work a workflow starts
  • Environments — the Docker Compose containers jobs run in

API and SDK

  • API Authentication — how to get and use access tokens
  • API Reference — the SaturnCI API
  • SDK — the Ruby gem workflows are written against
